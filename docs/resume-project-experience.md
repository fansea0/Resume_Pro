# 项目经历

## Resume Pro | AI 简历优化与模拟面试平台

**技术栈：** Go、Gin、CloudWeGo Eino、SQLite、Redis、SSE、OpenAI 兼容 API（DeepSeek / MiniMax）、React、TypeScript、Vite、JWT

**项目介绍：**

面向求职场景的本地优先简历平台，基于 CloudWeGo Eino Agent 编排实现目标岗位（JD）对齐的简历章节润色与多轮 AI 模拟面试，覆盖「优化表达 → 投递 → 面试 → 总评」闭环。

**主要工作：**

* **AI 章节润色：** 模型只产出结构化 edits 而非直接改写全文，服务端以 LCS diff 计算变更锚点、逐条生成可审阅建议，并做**数字接地校验**（新增数字必须已在原文出现），杜绝模型编造业绩数据；配合 JSON Schema 强约束输出与**契约修复重试**机制，输出不合法时携带校验错误回灌重试。

* **Agent 编排与状态持久化：** 基于 Eino Graph 设计提问、评分、追问决策、总评、收尾五节点编排，**StatefulInterrupt** 实现跨请求挂起恢复，Redis checkpoint 持久化会话游标与追问预算，支持服务重启后继续面试。

* **面试评分算法：** 设计 C / B- / B / B+ / A / S 六档**序数评分**，总评采用**中位数定基础档、比例门槛定高档**的组合策略，避免均值被个别极端评分拉高，同时用 **ClampGrade** 保证追问链上评分只升不降。

* **全链路 Trace 与可观测：** 将 AI 调用 Hook 扩展至面试图全部节点（生题、评分、追问决策、总评），按节点记录租户、操作类型、耗时、输入输出 Token 与重试次数；以 **trace id** 串联单次面试的完整调用链，节点异常时携带**节点名与错误原文**落日志并透传前端，故障可按 trace 精确定位到环节。

**规模数据：** 270 次提交 · 75 个测试文件（Go 37 / 前端 38）· 13 套简历模板 · 37 个后端模块 · 170+ 源文件
