# Apple 式简历体验改版设计

## 产品目标

让用户以“选择模板”作为唯一明确起点，在始终可见的简历预览旁专注填写内容。视觉采用 Apple 官网式留白与层级，编辑和后台则采用设置页式的克制分组；减少边框、操作噪声和决策负担。

## 模板主页

登录后的默认页仍是模板主页。页头只保留产品名、主导航与账号信息；主体采用居中标题、大留白与三列模板卡。

每张模板卡包含完整静态预览、名称、简短风格说明和 2–3 个适用岗位标签。整个卡片可点击并直接进入编辑器，按钮不再占用额外视觉注意力。禁用模板继续从普通主页隐藏。

模板注册元数据扩展为 `tags: string[]` 和 `styleDescription: string`。它们是所有模板（包括后续从图片生成的模板）的必填静态字段，不属于用户简历数据。

## 编辑体验

桌面端保持左侧编辑、右侧固定实时预览的双栏结构。左侧的基本信息、工作经历、项目经历、教育经历和技能改为原生可访问的折叠分组；基本信息默认展开，用户打开一个分组时保持其他分组状态，不强制手风琴互斥。

保存使用 800ms 防抖自动保存：首次编辑自动创建草稿，后续编辑更新同一草稿。保存条显示“正在保存”“已保存”或可恢复的失败状态；仍保留“立即保存”以供用户主动确认。并发保存以版本号抑制旧响应覆盖新内容，卸载与切换草稿时取消待执行保存。

## 草稿与后台

草稿和后台沿用设置页式分组：更少阴影、更轻的分隔线和紧凑的列表行。后台模板行展示预览、名称、标签、风格说明和可用状态；保留现有的禁用确认与 API 语义，不增加恢复或复杂删除策略。

## 模板生成 skill

`resume-template-from-image` 的输出增加模板元数据要求：生成稳定 ID、中文名、2–3 个中文岗位标签和一句风格说明；注册表与测试都要包含它们。静态预览继续使用固定的完整样例简历，禁止使用用户或参考图的个人数据。

## 验证

- RTL：模板卡展示标签/风格并可通过整卡选择；编辑分组可折叠；自动保存防抖创建、更新、失败和立即保存；后台展示元数据。
- 类型/注册表测试：每个模板都有非空标签和风格说明。
- 全量运行前端 Vitest 和生产构建；在桌面与窄屏截图检查双栏、卡片、折叠区和固定预览布局。
