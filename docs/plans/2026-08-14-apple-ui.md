# Apple 式简历体验改版 Implementation Plan

> **For implementer:** Use TDD throughout. Write failing test first. Watch it fail. Then implement.

**Goal:** 以选择模板为核心入口，提供克制的 Apple 式页面层级、折叠编辑器、实时预览和可靠的自动保存，并让所有模板具备岗位标签与风格说明。

**Architecture:** 模板静态注册表新增元数据字段，gallery/admin 从同一注册表读取。保存逻辑抽为前端 hook，使用 800ms 防抖与版本保护；`App` 持有已保存简历 ID，使自动创建后更新同一记录。视觉只通过现有 React/CSS 重构，不增加 UI 库或后端 API。

**Tech Stack:** React、TypeScript、Vitest、React Testing Library、现有 REST API、CSS。
